# 红动漫社萌战 · 用户手册

面向部署者与普通使用者的简要说明。协同开发请参阅 [设计说明书](./设计说明书.md)。

---

## 1. 项目简介

**红动漫社萌战**是面向校园二次元角色人气投票的活动站点（B 站萌战活动页风格），支持：

- **决斗赛**：两人一对一，票比条对决
- **小组赛**：组内 n 人，每人最多选 m 人（n 选 m）
- **战报**：历史得票与胜者统计
- **管理后台**：创建对阵、维护角色与图集、删除评论

当前可运行代码位于仓库的 `demo/` 目录（Next.js）。

---

## 2. 本地安装与启动

### 环境要求

- Node.js 20+（已在 Node 24 验证）
- npm 10+

### Windows 一键启动

双击 `demo/start.bat`（会安装依赖、初始化数据库、启动并打开浏览器）。

### 命令行

```bash
cd demo
cp .env.example .env   # Windows 可用 copy .env.example .env
npm install
npm run setup          # 生成 Prisma Client + 建表 + 种子数据
npm run dev
```

浏览器打开：**http://localhost:3000**

### 常用命令

| 命令 | 作用 |
|------|------|
| `npm run dev` | 开发服务器 |
| `npm run build` / `npm start` | 生产构建与启动 |
| `npm run db:reset` | 清空并重新播种数据库（开发用） |
| `npm run db:seed` | 仅重新执行种子脚本（需库已存在） |

> 请勿在 `萌战/` 目录运行 npm；也不要直接双击 HTML 文件。

## 3. 配置说明（环境变量）

从 `.env.example` 复制为本地配置文件后按需修改。

| 变量 | 含义 | 本地建议 |
|------|------|----------|
| `DATABASE_URL` | SQLite 路径 | `file:./dev.db` |
| `VOTE_TOTAL_LIMIT` | 每用户全局票数上限 | `5` |
| `ALLOW_DEV_LOGIN` | 允许昵称模拟登录 | `true`（本地） |
| `REQUIRE_WECHAT_LOGIN` | 要求绑定微信身份 | 本地可与开发登录配合 |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | 管理员账号 | 按部署需要设置 |
| `WECHAT_*` / `AUTH_SECRET` | 微信 OAuth 与会话签名 | 生产必填；本地可不填 |

本地默认：访问 `/login` 输入任意昵称即可模拟登录（`ALLOW_DEV_LOGIN=true`）。昵称 **不要** 使用 `admin`（与管理员账号冲突）。

## 4. 网站功能（普通用户）

### 4.1 页面一览

| 路径 | 功能 |
|------|------|
| `/` | 对阵投票主页 |
| `/report` | 萌战战报（得票与胜者） |
| `/characters` | 角色总览 |
| `/characters/[slug]` | 角色详情（简介 / 图集 / 评论 / 得票） |
| `/me` | 个人中心：票数、投票记录、退出 |
| `/login` | 登录 |
| `/about` | 赛制说明 |
| `/admin` | 管理后台（仅管理员） |

### 4.2 登录与票数

1. 打开「登录」，本地用昵称模拟登录；正式环境应在微信内完成授权。
2. 登录后右上角显示昵称与**全局剩余票数**。
3. 点击右上角账号进入「我的」可查看历史投票并退出。

### 4.3 对阵主页投票

1. 顶部三个分栏：**进行中 / 未开始 / 已结束**（仅「进行中」可投票）。
2. 再按 **A/B/C… 组** 筛选；可开「票数排序」（主要影响小组赛展示）。
3. 根据对阵类型操作：
   - **决斗赛**：选择一方「投给 XXX」，确认后消耗 1 票。
   - **小组赛**：角色网格中点击「投票」；每人最多选 **m** 个不同角色，已投显示「已投票」。
4. 头部会提示本组还可投 `x/m`；同时受全局票数限制。
5. 票比约每 10 秒自动刷新。

### 4.4 战报

「战报」页可查看：

- 已结束 / 进行中 / 未开始数量与累计票数
- 胜者榜
- 各对阵得票详情（决斗为 VS 条；小组赛为排名网格）

### 4.5 角色与评论

- 角色页可浏览简介与图集，发表评论（含敏感词过滤）。
- 「得票」页签可查看该角色在各对阵中的表现。

## 5. 管理界面使用说明

### 5.1 如何进入

1. 若当前已用普通账号登录，请先到「我的」**退出**。
2. 浏览器直接打开 `/admin`（或未登录时导航不会显示「管理」）。
3. 使用环境变量中的 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 登录（示例见 `.env.example`）。
4. 登录成功后，导航会出现「管理」入口，且仅该管理员会话可见。

### 5.2 对阵管理

可创建两类**对阵组**：

| 类型 | 配置要点 | 前台表现 |
|------|----------|----------|
| 决斗赛（1v1） | 选 2 名角色；每人上限固定为 1 | VS 对阵卡 + 票比条 |
| 小组赛（n 选 m） | 至少 3 名角色；设定每人可选上限 **m**（m ≤ n） | 角色网格 + 各自票数 |

同时可设置：

- **组别字母**（A–Z）
- **轮次名称**（可选）
- **投票起止时间**（仅窗口内可投）

列表中可：

- **改时段**：调整开始/结束时间
- **立即结束 / 重新开放**

### 5.3 角色管理

- 新建 / 编辑角色（名称、作品、简介、emoji、主题色、分组等）
- 上传 / 清除立绘
- 管理图集（上传、删除）
- 删除角色（会连带删除其参与的对阵组，请谨慎）

### 5.4 评论管理

- 查看全站评论列表
- 删除不当评论

## 7. 正式上线前 checklist

1. 按部署环境设置管理员账号与会话相关配置，关闭 `ALLOW_DEV_LOGIN`
2. 配置真实微信服务号 / 测试号 OAuth（公网 HTTPS 域名，**不能**用 localhost）
3. 上传图与数据库文件按需备份
4. 使用 `npm run build` 验证构建，再用 `npm start` 或平台部署

微信授权详细步骤见 [设计说明书](./设计说明书.md)「待完成 / 上线相关」章节。

## 8. 常见问题

| 问题 | 处理 |
|------|------|
| 页面空白 / 连不上 | 确认已在 `demo/` 执行 `npm run dev` |
| 数据库错误 | 执行 `npm run setup` 或 `npm run db:reset` |
| 看不到「管理」 | 必须用 admin 专用账号登录 `/admin`，普通用户无入口 |
| 无法投票 | 检查是否登录、全局票是否用尽、对阵是否在「进行中」、本组 m 是否已用完 |
| 真实微信登录失败 | localhost 无法作授权域名，需公网 HTTPS + 公众平台配置 |

更多技术细节与接口列表 → [设计说明书](./设计说明书.md)
